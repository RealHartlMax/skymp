# SkyMP Docs

Welcome to the SkyMP documentation portal. Here you will find practical guides, API references, server manuals, and maintenance notes.

Current server checkout audit: **24 October 2026**. Start with [project status and completed/open TODOs](docs_project_status.md), [Linux/Windows browser setup](docs_linux_vps.md), [VPS firewall and game process control](docs_vps_ports_and_process_control.md), [Discord bot and game monitoring](docs_discord_bot.md), [Steam, guest access and Legacy in-game login](docs_ingame_login.md), [launcher mod packages](docs_launcher_modpacks.md), and [versioned client/SKSE packages](docs_launcher_runtime_updates.md). For server extensions see [Plugin System guide](../README-plugins.md), including packaging, dashboard management and required game-server restarts. For voice see [Lipsync status and required information](docs_voice_lipsync_status.md) and [Voice Activity API](docs_voice_api.md). Current path is partial and still needs real Skyrim/TeamSpeak acceptance. Local build/download checks and real Skyrim/CEF gameplay acceptance are recorded separately.

For sessions that end by kick, ban, restart or connection loss, see [session end](docs_session_end.md). For console protection, see [console security](docs_console_security.md).

## Project Status (WIP Fork)

This fork is currently a **work in progress**.

Some features are usable, but not every component has been tested on all host setups. This is one reason the fork is not integrated into the main repository yet.

We are actively looking for testers who can:

1. Set up their own servers on different systems.
2. Validate gameplay and admin workflows in real environments.
3. Report bugs, crashes and configuration issues.

Every system differs, so real-world feedback is extremely valuable.
