# SP 2.7.1 Versionshinweise

Dieses Dokument enthält die Änderungen seit SP 2.7.0

WARNUNG: SP kann Spielstände beschädigen. Sichere deine Spielstände vor der Installation. Siehe https://github.com/skyrim-multiplayer/skymp/issues/796

SP unterstützt die Steam-Version von Skyrim SE (1.6.640) und die ältere Version 1.5.97.

<a id="changes"></a>

## Änderungen

- Fehlermeldung von DirectoryMonitor bei fehlendem Verzeichnis verbessert.

- Absturz beim Speichern/Laden im Zusammenhang mit `cellAttach`/`cellDetach` behoben.

- Zufälligen Startabsturz im Zusammenhang mit Chromium behoben.
