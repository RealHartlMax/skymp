Neues optionales Argument `overrideFolder` für `writePlugin` und `getPluginSourceCode`: Dieser Ordner darf außerhalb der in `PluginFolders` definierten Plugin-Ordner liegen. Er ist lesbar und beschreibbar, wird aber von SkyrimPlatform weder überwacht noch zum Laden von Plugins verwendet. `overrideFolder` ist relativ zu `Data/Platform`.
