Dies ist ein Beispiel für Versionshinweise zu einer Änderung in einem Themenzweig. Entwickler sollten für jeden Zweig mit einer wesentlichen Änderung ähnliche Hinweise ergänzen. Dateiname und Überschrift müssen dem Themennamen entsprechen, um Merge-Konflikte zu vermeiden.
