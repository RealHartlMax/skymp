# Server-Kommandozeilen-API

In den ersten Monaten der heutigen skymp-Servergeneration verwendeten wir eine Kommandozeilen-API zur Konfiguration. Heute gibt es eine [JSON-Konfigurationsdatei](docs_server_configuration_reference.md); CLI-Optionen werden nicht mehr unterstützt.
