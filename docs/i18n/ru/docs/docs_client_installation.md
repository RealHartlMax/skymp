# Установка клиента

Проверено по локальному fork и launcher **22 октября 2026 года**.

<a id="install-with-the-standalone-launcher"></a>

## Установка через отдельный launcher

1. Установите собственный Skyrim Special Edition/Anniversary Edition и выберите в launcher каталог с `SkyrimSE.exe`.
2. Выберите сервер и **Подготовить файлы** для проверки без запуска Skyrim.
3. Launcher получает манифест модов сервера, проверяет локальные master и загружает опубликованные файлы с проверкой размера/SHA-256.
4. Если сервер предлагает полный каталог версий клиента, launcher выбирает соответствующую версию Skyrim и может установить SKSE и Address Library. Вручную выбранный пакет клиента имеет приоритет.
5. **Подключиться** запускает SKSE только после успешной подготовки. Отсутствующий или противоречивый пакет блокирует запуск.

Для файлов оператора игрокам не нужен аккаунт Nexus/Vortex. Игра и соответствующие master-файлы Bethesda остаются локальными требованиями. См. [пакеты модов](docs_launcher_modpacks.md), [каталоги версий клиента](docs_launcher_runtime_updates.md), [SkyMP Worlds](docs_launcher_worlds.md).

<a id="manual-or-legacy-installation"></a>

## Ручная или устаревшая установка

Сборка исходников создаёт `build/dist/client`. Скопируйте содержимое в каталог Skyrim, сохраняя `Data/...` и структуру пакета. Установите SKSE для **точной версии игры** и выпуска клиента; не выбирайте загрузку только по общей подписи «текущая SE». Официальные загрузки SKSE: <https://skse.silverlock.org/>. Установите соответствующую Address Library и требуемые сервером моды/порядок загрузки.

DLL runtime размещаются по путям пакета клиента, включая `Data/SKSE/Plugins/` и `Data/Platform/Distribution/RuntimeDependencies/`. Настройки соединения отдельно в `Data/Platform/Plugins/skymp5-client-settings.txt`; личные данные входа не должны попадать в распространяемый runtime-пакет.

<a id="compatibility-and-test-boundary"></a>

## Совместимость и граница проверки

Локальный порт CommonLib теперь собирает клиентские DLL и проходит независимые проверки форматов Address Library 1/2/5, включая базу 1.7.104. Это **не** доказывает работу каждого нативного перехватчика, CEF или многопользовательской сессии на Skyrim 1.7.104. Старая сторонняя нативная DLL всё ещё может отказать при инициализации SKSE до любого соединения с сервером.

Полная игровая проверка остаётся открытой. Датированные свидетельства приведены в [статусе проекта](docs_project_status.md). Отличайте установку/загрузку пакета от успешной игры с ним.
