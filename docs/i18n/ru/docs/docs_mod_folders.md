# Размещение модов в `data/mods`

Каждый мод находится на сервере в отдельной папке. Это заменяет `client-resources`, который больше не читается. На ПК игрока ничего не меняется: Skyrim и SKSE загружают файлы только из `Data/`, поэтому лаунчер по-прежнему устанавливает их туда.

## Структура

```text
data/
  Skyrim.esm
  mods/
    RaceMenu/
      RaceMenu.esp
      RaceMenuPlugin.esp
      RaceMenu.bsa
      SKSE/Plugins/skee64.dll
      SKSE/Plugins/skee64.ini
```

На ПК игрока `data/mods/RaceMenu/SKSE/Plugins/skee64.ini` становится `Data/SKSE/Plugins/skee64.ini`.

## Правила

- Папка раздаётся, если активен один из её плагинов или в ней вообще нет плагинов.
- Плагины включаются в dashboard и сохраняются в `loadOrder` как `mods/RaceMenu/RaceMenu.esp`. Плагины прямо в `data/` продолжают работать.
- Если два мода содержат один и тот же файл, побеждает папка, расположенная позже. Порядок хранится в `modFolders`, иначе используется алфавитный порядок. Dashboard показывает конфликты.
- Файлы, которые нельзя раздавать, пропускаются и перечисляются в dashboard. Исходные и отладочные файлы (`.pdb`, `.h`, `.psc`) и папки `fomod`, `ModderResource` и `Source` игнорируются без уведомления.
- Сервер также читает `Scripts` и `Strings` из папок модов. При совпадении скриптов здесь тоже побеждает папка, расположенная позже.

## SKSE DLL

DLL являются исполняемым кодом и подходят только к определённой версии Skyrim. Поэтому они раздаются, только если выполнены все условия:

1. Оператор включает DLL папки в dashboard. Это сохраняется в `launcherResources.skseFolders`.
2. Оператор указывает версию Skyrim в `launcherResources.skseGameVersion` из четырёх частей, например `1.6.1170.0`.
3. Игрок подтверждает каждую DLL в лаунчере. Подтверждение действует для сервера и хеша файла; при изменении файла лаунчер спросит снова.
4. Установленная версия Skyrim совпадает. Иначе лаунчер прерывает работу.

Runtime DLL `SkyrimPlatform.dll` и `MpClientPlugin.dll` заменить нельзя. С DLL манифест имеет версию 4; старые лаунчеры отклоняют его, а не пропускают DLL молча. Поэтому игрокам нужен актуальный лаунчер.

## Переход с `client-resources`

Сервер больше не публикует `client-resources` и предупреждает при запуске, если там ещё есть файлы. Переместите содержимое `client-resources/Data/` в `data/mods/<мод>/` и перезапустите сервер. Обновления не удаляют старую папку. Поле `launcherResources.directory` больше не используется.

Клиентской runtime и runtime плагинов это не касается.

## Безопасность

Каталог `data/` больше не раздаётся публично. По HTTP из него доступен только `/manifest.json`; файлы модов идут через загрузки лаунчера.

## Состояние проверки

Серверная часть покрыта тестами. Изменения лаунчера ещё не собраны и не проверены через `cargo test`, а в игре ещё ничего не проверено.
