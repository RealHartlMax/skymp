# SP 2.7.1 Примечания к выпуску

В документе перечислены изменения после SP 2.7.0

ПРЕДУПРЕЖДЕНИЕ: SP может повредить сохранения. Перед установкой сделайте резервные копии. См. https://github.com/skyrim-multiplayer/skymp/issues/796

SP поддерживает Steam-версию Skyrim SE (1.6.640) и старую версию 1.5.97.

<a id="changes"></a>

## Изменения

- Улучшено сообщение DirectoryMonitor об отсутствующем каталоге.

- Исправлен сбой при сохранении/загрузке, связанный с `cellAttach`/`cellDetach`.

- Исправлен случайный сбой Chromium при запуске.
