# SP 2.9.0 Примечания к выпуску

Спасибо за использование Skyrim Platform!

В документе перечислены изменения после SP 2.8.0

ПРЕДУПРЕЖДЕНИЕ: требуется новая игра. Обновление на текущем сохранении — на свой риск. Сделайте резервные копии сохранений.

Подробнее о состоянии проекта: https://github.com/skyrim-multiplayer/skymp/blob/main/skyrim-platform/README.md

<a id="changes"></a>

## Изменения

- После серии отдельных исправлений устранены все оставшиеся небезопасные обработчики событий. **Сбои при загрузке сохранения больше не должны возникать.** ❤️‍🩹

- Добавлена поддержка Skyrim 1.6.1170.0. ❤️‍🩹

- Добавлена нативная функция `TESModPlatform.CreateReferenceAtLocation`.

- Исправлен сбой загрузки сохранения с хотя бы одним активным слушателем `effectStart`/`effectFinish`.

- Немного оптимизировано API текстов.

- В событие `playerBowShot` добавлено отсутствовавшее значение `isSunGazing`.

- Функция `loadGame` теперь работает с нестандартными частями головы.

- `blockPapyrusEvents` больше не блокирует события в скрипте `defaultDisableHavokOnLoad`.

- Значительно оптимизировано API настроек.

- Добавлена нативная функция `TESModPlatform.CloseMenu`.

- `setInventory` теперь по умолчанию разрешает снимать экипированные предметы игроку; для остальных актёров запрет сохраняется.

- Исправлен сбой горячей перезагрузки после попытки зарегистрировать слушатель несуществующего события.

- Добавлен метод `blockPapyrusEvents` как псевдоним Papyrus-функции `TESModPlatform.blockPapyrusEvents`, требующей контекст `on('update')`.

- [Встроенная консоль](https://github.com/skyrim-multiplayer/skymp/blob/592c6527ed91e6c97a38d143f4ae1cdab9c3268e/docs/release/sp-2.8.md?plain=1#L68) теперь корректно отражает необработанные исключения игровой консоли.

- В `loadGame` добавлены параметры `time` и `loadOrder`.

- Исправлены ошибки выполнения, возникавшие, когда сборщики считали const enum в skyrimPlatform.ts неконстантными.

- Добавлена начальная поддержка скриптовых функций в контексте tick: `Game.getModCount`, `Game.getModName`.

- Исправлен потенциальный сбой загрузки сохранения с хотя бы одним активным слушателем `magicEffectApply`.

- Добавлена экспериментальная нативная функция `TESModPlatform.EvaluateLeveledNpc`. Она нестабильна и не должна использоваться в пользовательских плагинах; эта функция нужна SkyMP.

- Исправлен сбой события `CameraStateChanged` при открытии карты мира.

- HTTP Client API теперь поддерживает обратные вызовы наряду с Promise. Это полезно, поскольку в главном меню SkyrimPlatform Promise не разрешаются.
