# Загрузчик runtime плагинов

Реализация и контракт для операторов/разработчиков поддерживаются в [misc/plugin-runtime/README.md](../misc/plugin-runtime/README.md).

Это изменение исходников для планируемой серверной версии **v2.1.0**: расширение публичного манифеста launcher и универсальный API модулей клиента/CEF. Это не только исправление ошибок для v2.0.2. Версии launcher и плагинов управляются независимо.

Подготовка исходников также включает:

- Офлайн-инвентарь читает настроенную нативную файловую базу (`databaseName`, по умолчанию `world/changeForms`), определяет аутентифицированный профиль вместо использования слота соединения как профиля и предпочитает ещё загруженного нативного актёра. Пустой инвентарь — корректный снимок. Исторические записи без известного профиля получают локализованный явный статус; идентичность не угадывается.
- Офлайн-игрокам нельзя выполнять живые действия модерации. Перед записью успеха backend проверяет текущее соединение и, если передан, ожидаемый профиль.
- Запрос инвентаря не может перезаписать более новый выбор игрока. Источник, время и состояния недоступности локализованы.
- Проверка версии сервера по умолчанию использует `RealHartlMax/skymp`; `releaseRepository` может задать другой проверенный `owner/repository`.

Существующие локальные артефакты выпуска предшествуют этим изменениям исходников. Во время этой реализации не выполнялись новая сборка, ZIP, commit, push, tag или выпуск. Будущая сборка должна совместно включать launcher, общий bootstrap клиента/CEF и пакеты Runtime плагинов. После этого разового обновления совместимые изменения UI/клиента плагина входят в его собственный выпуск.
