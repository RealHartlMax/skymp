# Документация SkyMP

Добро пожаловать в портал документации SkyMP. Здесь практические руководства, справочники API, серверные инструкции и заметки сопровождения.

Аудит серверных исходников: **24 октября 2026**. Начните со [статуса и завершённых/открытых задач](docs_project_status.md), [настройки Linux/Windows в браузере](docs_linux_vps.md), [firewall VPS/управления игрой](docs_vps_ports_and_process_control.md), [Discord-бота/мониторинга](docs_discord_bot.md), [Steam/гостей/Legacy-входа](docs_ingame_login.md), [mod-пакетов Launcher](docs_launcher_modpacks.md), [версионированных client/SKSE-пакетов](docs_launcher_runtime_updates.md). Расширения: [система плагинов](../README-plugins.md), включая упаковку, dashboard и необходимые перезапуски игры. Голос: [Lipsync-статус/нужные сведения](docs_voice_lipsync_status.md), [Voice Activity API](docs_voice_api.md). Путь частичный, настоящая Skyrim/TeamSpeak-приёмка открыта. Локальные build/download и реальная Skyrim/CEF-игра учитываются отдельно.

О сессиях, завершённых киком, баном, перезапуском или потерей соединения, см. [завершение сессии](docs_session_end.md). О защите консоли см. [Console Security](docs_console_security.md).

## Статус проекта: fork в разработке

Fork пока **в разработке**.

Часть функций пригодна, но не все компоненты проверены на всех хостах. Поэтому fork пока не включён в главный репозиторий.

Нужны тестировщики, которые:

1. Установят свои серверы на разных системах.
2. Проверят игру/административные процедуры в реальной среде.
3. Сообщат ошибки, сбои, проблемы конфигурации.

Каждая система отличается, поэтому практические отзывы особенно ценны.
