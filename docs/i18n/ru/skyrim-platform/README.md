# Skyrim Platform

Создавайте Skyrim-моды на JavaScript/TypeScript. Руководство предназначено желающим писать такие моды или использовать их.

## Поддерживаемые игры

Ранее документированные цели:

- Skyrim SE/AE 1.6.1170.
- Skyrim SE/AE 1.6.640.
- Skyrim SE 1.5.97.0.8, устарела; ошибки больше не принимаются.

Локальный форк на **22 октября 2026 года**: CommonLib перенесена на 7.5.4, созданы новые релизные DLL и отдельные проверки Address Library форматов 1/2/5, включая Skyrim 1.7.104. Полная SKSE/CEF/игровая приёмка открыта. Одна Steam-версия или успешный reader-тест совместимость не подтверждает. См. [статус](../docs/docs_project_status.md), [установку](../docs/docs_client_installation.md).

## Авторам модов

Преимущества:

- **JavaScript:** JSON, RegExp, классы, функциональное программирование, npm.
- **Hot reload:** SP следит за плагинами; Ctrl+S/Alt+Tab — проверка в игре.
- **IDE:** многие ошибки видны при компиляции.
- **Promises/async/await:** для асинхронных Papyrus, например `Utility.wait`, `ObjectReference.setPosition`.
- **Безопасность:** защита от null pointers, проблем потоков и др.
- **SKSE:** вызов сторонних функций напрямую из JS/TS.
- **Менеджеры модов:** ничего в корень Skyrim.
- **CEF:** игровой UI на React, VueJS и т. п.

Недостатки:

- Ограниченный MCM.
- Недостаточная поддержка сохранений; управлять состоянием бывает сложно.
- Пользователю нужно скачать Skyrim Platform.
- Анимации Chromium снижают FPS.
- Несколько Chromium-интерфейсов поддерживаются плохо, нужны обходы.

Особенно удобно для:

### JavaScript-разработчика без опыта моддинга

Знакомый стек доступен для Skyrim.

### Человека с СДВГ

Hot reload даёт быстрые прототипы и короткую обратную связь, гораздо быстрее разработки Papyrus/C++.

Это хорошая отправная точка Skyrim-программирования; позже можно перейти к C++, как делают многие.

См. [документацию](https://github.com/skyrim-multiplayer/skymp/blob/main/docs/docs_skyrim_platform.md), [пример](https://github.com/skyrim-multiplayer/skymp/tree/main/skyrim-platform/tools/plugin-example). Удачи!

## Пользователям SP-модов

Последний выпуск — на [Nexus Mods](https://www.nexusmods.com/skyrimspecialedition/mods/54909). У использования есть ограничения:

- **Используйте [SSE Engine Fixes](https://www.nexusmods.com/skyrimspecialedition/mods/17230):** иначе Chromium может остаться в диспетчере после выхода.
- **SkyrimPlatform исполняет плагины:** падение FPS обычно связано с неоптимизированным плагином; возможности платформы это исправить ограничены.
- **Много конфликтов с модами:** учитывайте совместимость.
- Для SkyrimPlatform 1.5.97 отчёты не принимаются.
- **Обновление/удаление может повредить старые сохранения:** нужно начать новую игру.
- **Часто сохранения ремонтируются:** см. [закреплённые сообщения Nexus](https://www.nexusmods.com/skyrimspecialedition/mods/54909?tab=posts).

## Планы

- **Ошибки/совместимость:** проект и автор направят доступные силы на исправления.
- **Переход NodeJS:** сейчас используется [ChakraCore](https://github.com/chakra-core/ChakraCore).
- **Производительность вызовов:** внутренние ES6 Proxy нужно оптимизировать.
- **Документация:** описать недокументированные API, вклад приветствуется.
- **SkyMP как игра:** мультиплееру нужны собственные скрипты, поэтому часть SkyrimPlatform API реализуется на сервере.

## Частые вопросы

**Как распространять?** Скомпилированным JS, см. `tsconfig.json` примера. Поставляйте `your-plugin-name.js`, пользователи кладут в `Data/Platform/Plugins`.

**Как дать настройки подобно SKSE ini?** Есть Settings API. Файлы также в `Data/Platform/Plugins`, с суффиксом `-settings.txt`, например `your-plugin-name-settings.txt`.

**Как создать?** В архиве `Data/Platform/plugin-example`, его README описывает пример.

**Как hot reload?** Выполните `Data/Platform/plugin-example/README.md`, затем Ctrl+S в редакторе.
