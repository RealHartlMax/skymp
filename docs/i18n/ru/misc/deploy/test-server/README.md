# Тестовая версия сервера SkyMP

> **Новое:** моды теперь находятся в `data/mods/<мод>/`; `client-resources` больше не читается. Сведения о нём на этой странице устарели. См. [моды в data/mods](../../../../../../docs/docs_mod_folders.md).

Windows/Linux содержат одинаковые backend/frontend/gamemode. `build-manifest.json` фиксирует исходники, платформу и SHA256 каждого файла. Нативное расширение собрано отдельно для ОС.

## Полная установка или обновление

Linux `*-full.zip` содержит начальные настройки и распаковывается только в новый пустой каталог. Для существующего сервера используйте `*-update.zip`: программные файлы без изменения конфигурации, паролей, `data/`, мира, модов, клиентских ресурсов, своих файлов и `gamemode.js`. Сохраните копии, остановите всю службу с панелью, распакуйте с заменой и запустите. Вход сохраняется, новый PIN не нужен. Подробно: `UPDATE-VPS.md`.

`DASHBOARD.md` описывает настройки, метрики, историю обрывов и плановые рестарты с часовым поясом/предупреждениями. Панель доступна при остановленной игре.

## Подготовка

1. Распакуйте Windows x64 либо Ubuntu 26.04 x86_64; `uname -m` должен показывать `x86_64` для Linux-пакета.
2. Скрипты проверяют runtime. Подходящий Node.js x64 22+ используется. При отсутствии/старой версии скачивается текущий Node.js 22 LTS с nodejs.org, проверяется SHA-256 и ставится только в `.runtime/` этого сервера. Ubuntu/Debian точечно ставят недостающие пакеты с root/noninteractive sudo. Windows при ошибке нативной загрузки устанавливает/обновляет подписанный Microsoft C++ runtime, возможно с административным запросом Windows.
3. Скопируйте пять файлов из `data/SPIELDATEN.txt` своей игры в `data/`. В пакетах игровых данных нет.
4. **Пакет первоначальной браузерной настройки** сначала показывает только адрес и случайный **четырёхзначный код**, без терминальных вопросов. Откройте `http://VPS_IP:8080/admin`, локально `http://127.0.0.1:8080/admin`, введите код. В браузере задаются имя, порты, слоты, доступ, публичный IPv4/домен и свой администратор. Пароль сохраняется только scrypt-хешем. Игра затем стартует автоматически; firewall не меняется.
5. Проверьте `server-settings.json`: UDP **7777**, HTTP **8080**. Тест использует Steam-гостей и 16 слотов. Введите Steam Web API Key; без него входа нет. 16 — тестовая настройка, не измеренная нагрузка.

## Запуск

Linux из распакованного каталога:

```sh
sh ./start-test-server.sh
```

Windows:

```bat
start-test-server.bat
```

`start-test-server.cmd`/`launch_server.bat` — Windows-псевдонимы, `launch_server.sh` — Linux. Проверяются ОС, Node и мастеры. Backend-зависимости включены, `npm install` не нужен. Другие серверы не затрагиваются. Повторный запуск пропускает настройку. Только настройка: `node setup-server.cjs`. Терминал не обязателен, код виден и в журнале службы, например `journalctl`.

Приватный Node проверяет обновления своей 22-LTS не чаще раза в 24 часа. Ошибка сохраняет проверенную версию. Подходящий глобальный Node не заменяется. `SKYMP_MANAGED_NODE=1` принудительно выбирает частный, `SKYMP_RUNTIME_OFFLINE=1` запрещает скачивание, но требует уже подходящий runtime. Мастеры/моды это не устанавливает.

## Быстрые действия и процессы

Стартер создаёт постоянное управление и отдельные дочерние панель/игру. **Остановить** освобождает UDP, но полная панель остаётся на том же HTTP с прежним входом, настройками, логами/загрузками; оттуда игру запускают снова. Меняется только игровой PID, панель/WebSocket сохраняются, как и настройки/аккаунты/миры. Сбой не вызывает бесконечный автоматический рестарт: остаются статус и ручной запуск.

Аккаунты/права проверяются и без игры. **Отключить всех** требует прав/игроков. Объявления/подтверждения используют свои диалоги. Прямой `node dist_back/skymp5-server.js` обходит управление и требует настроенного внешнего supervisor.

Ctrl+C/завершение всего стартера останавливает только собственную игру, не ищет другие серверы. Смена HTTP-порта/bind требует рестарта стартера, не только дочерней игры.

Живые действия требуют игры. Загрузкам нужен корректный `data/manifest.json`. Управление использует закрытый IPC без нового публичного порта. `PORTS-VPS.md` содержит HTTPS/firewall. В старой r2 при остановке была отдельная страница; для панели/бота берите согласованные r4-файлы.

При первой настройке только небольшой мастер слушает **все IPv4**, по умолчанию TCP 8080, UDP ещё закрыт. Разрешите TCP в VPS/provider-firewall либо используйте SSH. Выбранный доступ затем действует для панели. При смене порта используйте/разрешите новый. Если 8080 занят, заранее смените `uiPort`.

Код одноразовый на десять минут. Пять ошибок вызывают общую минутную паузу, затем новый код. Разрешение браузера — 30 минут. Рестарт до завершения создаёт новый код, не сохраняет неполное. Мастеры перепроверяются без рестарта. HTTP не шифрует настройку/вход; для постоянного доступа HTTPS/SSH.

Мастер резервирует прежний `server-settings.json`, создаёт `VERBINDUNG.txt` и `skymp5-client-settings.example.txt`. Последний — JSON-пример одного игрока, не готовый клиент. Существующий администратор не сбрасывается. Первоначальный пакет всегда в **новый каталог**; при обновлении не затирайте старые настройки стандартными.

## Панель на VPS

У подготовленных тестов данные в `TEST-ZUGANG.txt`, у браузерных установок — свой аккаунт. «Локально» связывает HTTP/UDP с loopback, «VPS с SSH» — UDP со всеми IPv4, HTTP loopback; «VPS с публичной панелью» — оба со всеми. Локально `http://127.0.0.1:8080/admin`.

Откройте туннель со своего ПК:

```sh
ssh -L 18081:127.0.0.1:8080 DEIN_BENUTZER@DEINE_VPS_IP
```

Откройте `http://127.0.0.1:18081/admin`, оставляя туннель. UDP 7777 нужен игровым тестам. Доступность HTTP клиентам/публичный HTTPS настраиваются отдельно сервером/прокси.

Для прямого доступа поставьте `uiListenHost: "0.0.0.0"` и перезапустите. `listenHost` управляет UDP, удалённым игрокам тоже нужен `"0.0.0.0"`. Адрес `http://VPS_IP:8080/admin`. `adminApi.externalUrl` не bind; при IP может быть пустым и выводиться из запроса.

При активном UFW разрешите порты:

```sh
sudo ufw allow 7777/udp
sudo ufw allow 8080/tcp
sudo ufw status verbose
ss -lnup
ss -lntp
```

Firewall провайдера также должен пропускать. Не включайте UFW только ради инструкции; правила SSH должны совпадать с настоящим портом. Для постоянного админа HTTPS/SSH, потому что HTTP не шифрует пароль.

## Подключение тестеров

Нужны обновлённый Windows-лаунчер/клиент и вошедший Steam. Лаунчер запрашивает билет, сервер проверяет Steam ID/выдаёт приватную сессию. Настройки `Data/Platform/Plugins/skymp5-client-settings.txt` управляются с backup/restore. Пример содержит адреса, не сессию. Произвольный `gameData.profileId` больше не даёт вход. Открытым гостям не нужен Worlds/skymp.net; возможно одобрение панели. Аккаунты/Discord — отдельные режимы. Подробности/ключ: `INGAME-LOGIN.md`.

Нужны совместимый Windows-клиент, SKSE/Address Library и мастеры. Серверный архив не содержит клиентские DLL и не исправляет их несовместимость.

## Моды через лаунчер

Дополнительные файлы — `client-resources/Data/` с игровой структурой. Плагины — `data/`/`loadOrder`; BSA публикуются автоматически. См. `client-resources/README.md`, `docs/docs_launcher_modpacks.md`.

Лаунчер читает `/api/launcher/manifest`, скачивает/проверяет размер/SHA-256, только затем запускает SKSE. Своя игра обязательна. Полная версионная runtime может установить SKSE, старой нужен предустановленный. Nexus/Vortex не требуются.

## Discord-бот

С r4 бот в независимом веб-сервере, соединение сохраняется при stop/restart/crash игры. Токен/ID/канал задаются в Настройки/Discord либо CFG/Discord, до r9 — Доступ и Discord. С r10 есть JSON-шаблоны/preview. Включите бота; сохранение применяет подключение и показывает статус. Работает и offline. Роли/права в `DISCORD-BOT.md`. Полный стартер обязателен.

## Порядок модов с r11

В **Ресурсах** пересканируйте ESM/ESP/ESL, включите и сохраните зависимости. Меняется только `loadOrder`; перезапустите игру. Файлы в серверном data; игрокам нужные копии также в `client-resources/Data/`. Выключенные исключены современным манифестом. См. `MOD-LOAD-ORDER.md`.

## Логотип и баннер

`logo.png`/`banner.png` рядом с настройками. Новые Full содержат изображения репозитория. Свои распознаются следующим heartbeat без веб-URL. Update их не заменяет. С r10 оба пакета также дают `server-assets/`, применяемый только без корневого изображения.

Рекомендуются **512 × 512** (1:1) и **1920 × 320** (6:1), PNG до 8 МиБ каждый. Важное размещайте по центру из-за обрезки. Изображения форка неизменны.

## Данные и обновления

Постоянные тестовые данные создаются в `data/`/`world/`. Сохраняйте конфигурацию, auth-store и миры перед заменой. У каждой браузерной установки свой аккаунт. Это тест сервера; Skyrim/CEF-клиента в пакете нет.
