# API 1 среды выполнения плагинов

Общая среда SkyrimPlatform содержит универсальный загрузчик нативных JS-модулей и хост CEF. Сам плагин владеет своим клиентским кодом, шаблонами интерфейса, CSS и публичными ресурсами. Пока API 1 совместим, обновление такого плагина не требует пересборки EXE лаунчера или общей клиентской среды. Для использования этих пакетов необходимо один раз установить базовый загрузчик и механизм скачивания в лаунчере.

## Структура плагина и активация

```text
Plugins/SkyMPChat/
  plugin.json                 # runtime: "Runtime/manifest.json"
  index.cjs                   # private server entry
  config.json                 # private server configuration
  Runtime/
    manifest.json
    client.js                 # optional native JS module
    ui.js                     # optional CEF module
    ui.css                    # optional stylesheet
    assets/...
```

Плагины, работающие только на сервере, не указывают `runtime`. Потребители UI-Core, например Metabolism, регистрируют виджеты и меню в UI-Core и не поставляют второй хост или браузер. У Chat, UI-Core и YACA есть собственные пакеты среды выполнения. Нативные DLL остаются частью централизованно распространяемой базовой среды, соответствующей версии Skyrim.

Сервер объявляет только плагины, успешно запущенные при текущем старте игрового процесса. Выбор в панели для следующего запуска хранится отдельно. После установки или отключения плагина перезапустите игровой сервер. Плагины-процессы удаляются из объявления при завершении. Исходники, манифест и файлы следует устанавливать вместе; после изменения установленных файлов нужен перезапуск. Изменения панели или её backend требуют перезапуска соответствующей службы.

## Публикация и скачивание

Публичный манифест лаунчера использует версию `3`, если нужны пакеты плагинов. Старый лаунчер остановится с существующей ошибкой неподдерживаемой версии. Серверы без таких пакетов сохраняют совместимость с версией `2`. Поле `pluginRuntime` содержит `{version:1,revision,packages:[...]}`. Для каждого пакета объявляются ID и версия плагина, SHA-256 исходных байтов манифеста, размер и URL манифеста, адресуемого по хешу.

Старый сервер без поля `pluginRuntime` сохраняет зафиксированные устаревшие мосты Chat/UI-Core. Для этого лаунчер записывает `plugin-runtime-managed:false`. Обновлённый сервер объявляет явный набор пакетов, в том числе пустой. Только этот набор поставляет интерфейсы плагинов; старые хосты отключаются. Поэтому удаление Chat/UI-Core на обновлённом сервере не активирует устаревший интерфейс заново.

- `GET /api/launcher/plugin-runtime/manifest`: текущее совокупное объявление пакетов.
- `GET /api/launcher/plugin-runtime/manifests/:sha256`: точные байты манифеста.
- `GET /api/launcher/plugin-runtime/files/:id`: явно объявленный публичный файл. ID — SHA-256 строки `manifestSha256 + "\0" + file.path`.

Издатель никогда не открывает весь каталог плагина рекурсивно. Скачиваются только объявленные файлы внутри `Runtime/`. Серверные сборки и конфигурация вне этого каталога не получают маршрутов скачивания. Символические ссылки, выход за пределы каталога, имена устройств Windows, нативные бинарные файлы, коллизии регистра и неподдерживаемые пути отклоняются. Текст передаётся как бинарные байты для сохранения хеша.

`contract.cjs` — канонический контракт проверки для генератора, сервера и нативного загрузчика. Каждый проект плагина содержит копию исходников SDK генератора в `tools/plugin-runtime/`; при изменении протокола эти файлы должны оставаться одинаковыми.

```json
{
  "formatVersion": 1,
  "pluginId": "skymp-chat",
  "version": "1.2.0",
  "requires": {"clientApi": 1, "uiApi": 1},
  "entrypoints": {"client": "client.js", "ui": "ui.js", "styles": ["ui.css"]},
  "files": [{"path": "client.js", "size": 123, "sha256": "64 lowercase hex characters"}],
  "signature": {"algorithm": "ed25519", "keyId": "publisher", "value": "128 lowercase hex characters"}
}
```

Пример сокращён: каждый входной файл и таблица стилей должны присутствовать в списке файлов. Неизвестные поля манифеста отклоняются. Ограничения: 128 активных пакетов, 256 файлов на пакет, 16 МиБ на файл, 64 МиБ на пакет, суммарно 256 МиБ активных файлов, 256 КиБ на манифест, 8 МиБ на активный индекс и 240 символов полного устанавливаемого относительного пути. Для каждой пары `(pluginId, version)` байты манифеста, включая подпись, неизменяемы. При изменении любого байта или ключа публикуйте новую версию. Лаунчер хранит журнал проверенных ревизий и отклоняет изменение уже существующей версии.

## Подпись издателя

Лаунчер и нативный загрузчик требуют подпись Ed25519 канонического JSON в UTF-8: ключи объектов рекурсивно отсортированы, порядок массивов сохранён, пробелов нет, всё поле `signature` исключено. Размеры — неотрицательные целые числа. Идентификаторы, пути и кодировки подписей ограничены контрактом. Генерация пакета использует `createRuntimeManifest` с явным списком публичных файлов. Для разработки можно создать неподписанный кандидат, но лаунчер его не примет и пакетирование релиза потребует подписанный манифест.

Используйте SDK из этого каталога или его идентичную копию в проекте плагина:

```powershell
# Once, outside the public plugin/runtime tree; keep the private file private.
node tools/plugin-runtime/package.cjs keygen --output C:/private/publisher.pem --key-id publisher
# The printed JSON maps publisher ID to its public key. Verify/distribute it independently.
$env:SKYMP_PLUGIN_SIGNING_KEY = 'C:/private/publisher.pem'
$env:SKYMP_PLUGIN_KEY_ID = 'publisher'
# On a later, explicitly requested build, the plugin's build tool signs its Runtime.
# Or sign an already built candidate without changing the file list:
node tools/plugin-runtime/package.cjs sign --root Runtime --private-key C:/private/publisher.pem --key-id publisher
```

Закрытый ключ нельзя хранить в `Runtime/` или включать в публичные архивы. Игроки вводят независимо проверенную карту **открытых** ключей в настройках лаунчера → игра → доверенные издатели плагинов. Ключи не берутся из объявления игрового сервера: сервер не может сам назначить себе доверие. Неизвестный издатель, изменённые байты, неправильная подпись, несовместимый API и изменение существующей неизменяемой версии останавливают подготовку до запуска Skyrim. В рамках исходной реализации постоянные ключи издателей и релизные пакеты не создавались. Автоматические тесты используют только временные одноразовые ключи.

## Установка и смена сервера

Сначала лаунчер скачивает базовую среду для версии игры и требует её возможность `pluginRuntimeApi:1`, затем проверяет все подписанные манифесты плагинов и файлы. Файлы плагинов устанавливаются только в `Data/Platform/PluginRuntime/packages/<pluginId>/<manifestSha256>/`. Закреплённый по хешу `active.json` привязывает полный набор пакетов к выбранным хосту и порту. Хеш индекса и независимо одобренные ключи издателей записываются в настройки клиента через существующий обратимый журнал установки. Для этих файлов действуют те же проверки коллизий, резервные копии и восстановление, что для других ресурсов лаунчера. При ошибке скачивания установка не активируется. При смене сервера лаунчер заменяет набор пакетов и восстанавливает файлы через тот же журнал. Прямой переход в игре на другой хост отклоняется, пока этот сервер не подготовлен в лаунчере.

Перед выполнением любого клиентского модуля нативный загрузчик повторно проверяет активный индекс, подпись и каждый файл. `client.js` — самостоятельный CommonJS-модуль, экспортирующий `apiVersion = 1` и `activate(api)`; последний может вернуть синхронную функцию очистки. Используйте внедрённые `api.sp`, `api.controller` и `api.constants.CustomPacket`, не импортируйте второй экземпляр SkyrimPlatform. Нативные подписки, обработчики событий, владение фокусом и зарегистрированные функции очистки удаляются при отключении, неудачной активации и перезагрузке. Доверенный нативный JavaScript обладает теми же правами, что другие скрипты SkyrimPlatform: проверка издателя не является песочницей.

Модуль CEF — самостоятельный скрипт, регистрируемый через `window.SkyMPPluginRuntime.register({pluginId,apiVersion:1,mount(ctx)})`. `mount` получает собственный DOM-корень, разрешение ресурсов, хост React/store/i18n, регистрацию reducer, методы фокуса, событий и очистки. Он может вернуть синхронную функцию очистки. Общие импорты: React, ReactDOM, React Redux, React i18next, React Draggable и React Resizable. Во время загрузки скрипта `require('skymp-plugin-host')` предоставляет текущий контекст. Используйте существующий браузер CEF. При очистке удаляйте дополнительные сокеты, таймеры и обработчики. CSS, ресурсы и ключи Redux принадлежат плагину; повторный владелец reducer запрещён. Удаление пакета очищает и его состояние Redux. Ошибка активации интерфейса выгружает набор пакетов и останавливает подключение. Игровые сообщения Chat/UI-Core сохраняют существующие серверные проверки.

YACA сохраняет установленный транспорт EventSource и нативного TeamSpeak. В стандартной серверной сборке интерфейс больше не встраивается в тело нативного EventSource: скачанный подписанный модуль владеет интерфейсом и очищает свой сокет и таймеры. При выгрузке нативный модуль YACA удаляет браузерный обработчик EventSource и завершает цепочку обновлений. Благодаря этому размер интерфейса больше не ограничивается лимитом 100 КиБ тела EventSource. `dist/ui/overlay.js` остаётся результатом инструмента для устаревших тестов. Явное `SKYMP_YACA_LEGACY_OVERLAY=1` при более поздней сборке включает этот резервный вариант. Текущий стандартный пакет требует новый базовый загрузчик. Ранее опубликованные старые плагины сохраняют совместимость через зафиксированные старые мосты.

## Приёмка перед релизом

Исходные тесты и проверки без генерации файлов не подтверждают установку лаунчером, работу настоящих Skyrim/CEF или голосового аудио. После отдельно разрешённых сборок подпишите манифесты, одобрите издателей, подготовьте один сервер, проверьте хеши скачанных файлов и запустите Skyrim. Проверьте Chat/UI-Core/Metabolism/YACA, перезапуск и повторное подключение, переход на сервер с другим, меньшим или пустым набором плагинов, очистку и восстановление. Изменённый файл, неизвестный издатель и повторно использованная версия с изменёнными байтами должны отклоняться. Отдельно проверяйте каждую поддерживаемую версию Skyrim, настоящее аудио TeamSpeak и видимую синхронизацию губ. Закрытые данные сервера и ключи издателей не должны попадать в релизные архивы.
