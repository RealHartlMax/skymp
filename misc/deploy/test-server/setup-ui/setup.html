Schritt 1 von 4

Server freigeben

Gib den vierstelligen Code aus dem Server-Terminal ein, um die Einrichtung in diesem Browser freizugeben.

Der Code ist 10 Minuten gültig und kann einmal verwendet werden. Nach fünf Fehlversuchen erscheint nach einer Minute ein neuer Code im Terminal.

Schritt 2 von 4

Dein Server

Wähle Namen, Ports und die Erreichbarkeit für deine Testgruppe.

16 ist ein Startwert für Tests. Die mögliche Spielerzahl hängt von deinem Server und Gamemode ab.

Ohne http://, Port oder Pfad. Diese Adresse verwenden deine Testspieler.

Launcher-Anbindung

Registriere den Server in SkyMP Worlds und trage die dort angezeigten Werte hier ein. Der Server speichert die Konfiguration automatisch.

Der Launcher liefert ein Steam-Ticket; der Server prüft damit die SteamID bei Valve. Die SteamID ist für jeden Login Pflicht. Ohne API-Key können keine Spieler beitreten. Ein vorhandener Schlüssel bleibt bei leerem Feld erhalten. API-Key bei Steam erstellen.

Aus dem zentralen Dashboard. Ein vorhandener Schlüssel bleibt erhalten, wenn dieses Feld leer bleibt. Er wird niemals an Spieler weitergegeben.

Ein Versionskatalog stellt das passende Clientpaket einschließlich SKSE bereit. Leer: kein Clientpaket über diesen Server vorgeben.

Schritt 3 von 4

Spieldaten prüfen

Kopiere diese fünf Masterdateien aus deiner Skyrim-Installation in data/ im entpackten Serverordner, zum Beispiel per SFTP. Sie sind im Download nicht enthalten.

    Schritt 4 von 4

    Dein Admin-Konto

    Mit diesem Konto meldest du dich künftig am Dashboard an. Der Einrichtungscode wird dafür nicht mehr benötigt.

    3–32 Buchstaben, Ziffern, Punkte, Unterstriche oder Bindestriche.

    Mindestens 10 Zeichen. Das Passwort wird nur als scrypt-Hash auf dem Server gespeichert.

    Einrichtung abgeschlossen

    Dein Server ist eingerichtet.

    Adressen und eine Vorlage für deine Testspieler findest du auch in VERBINDUNG.txt und skymp5-client-settings.example.txt im Serverordner.
